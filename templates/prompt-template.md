# 프롬프트 템플릿

`dispatch.sh`에 전달할 프롬프트다. 대괄호를 채우고 사용하지 않는 항목은 삭제한다. 각 항목의 목적은 `skills/orca-flow/SKILL.md`의 「프롬프트 필수 항목」을 참고한다. 프로젝트 전용 템플릿은 `.orca-flow.json`의 `promptTemplate`에 지정한다.

---

너는 [역할]이다. 이 워크트리는 [레포] 레포에 속하며, 여기만 수정한다.

## 참고 문서 (읽기 전용)

- [계약 문서의 절대 경로]의 「[절 제목]」
- [설계 결정 문서의 절대 경로]의 #[번호]

다른 레포의 문서는 워크트리에서 상대 경로로 접근할 수 없으므로 절대 경로를 적는다. 계약이 아직 머지되지 않았다면 해당 브랜치의 워크트리 경로를 지정한다.
예: `~/orca/workspaces/architecture/trade-contract-seam/specs/...`를 읽는다. 메인 체크아웃에는 최신 계약이 없다.
